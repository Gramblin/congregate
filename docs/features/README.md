# Congregate — Feature Docs

Congregate is a Muslim community platform with three pillars: **Community**, **Business**, and **Mentorship**. Users discover local communities, join events, launch and advertise businesses, receive sponsorships, request/pledge volunteers, follow mentors, and coordinate donation drives — all filtered by location.

See `PLAN.md` at the repo root for the phased roadmap.
